# DSA Lab 2 – Array Operations

In this lab, I performed three basic operations on arrays using C++.

## Tasks

1. **Searching an Array:** Searched for a number using Linear Search.
2. **Insertion in an Array:** Inserted a new element at a specific position.
3. **Deletion from an Array:** Deleted an element from a specific position.

## What I Learned

- How to work with arrays.
- How to search for elements.
- How to insert and delete array elements.
- How to use loops for array operations.

This lab helped me understand basic array operations and practice them in C++.

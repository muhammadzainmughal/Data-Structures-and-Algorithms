********# DSA Lab 3 – Linked Lists

In this lab, I learned how to create and work with singly and doubly linked lists using C++.

## Tasks

1. **Singly Linked List:** Created nodes and connected them using next pointers.
2. **Doubly Linked List:** Created nodes using previous and next pointers and displayed the list in both directions.

## What I Learned

- How to create nodes using pointers.
- How to connect nodes.
- How to traverse a linked list.
- Difference between singly and doubly linked lists.
- How to use `new` and `delete` for memory management.

## Conclusion

This lab helped me understand linked lists and how pointers connect nodes in C++.

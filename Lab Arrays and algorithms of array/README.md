# Data Structures and Algorithms Lab
## Array Insertion and Deletion in C++

### Introduction
In this lab, I learned how to perform insertion and deletion operations on arrays using C++. I practiced adding a new element at a specific position and deleting an element from a given position.

### 1. Array Insertion

In this task, I created an array and inserted a new element at a specified position.

**Working:**
- First, I displayed the original array.
- I selected the position where I wanted to insert a new element.
- I shifted the existing elements one position to the right to make space.
- I inserted the new value at the required position.
- Finally, I displayed the updated array.

**Example:**

Original Array:
```text
10 20 30 40
```

Value to insert: `25`

Position: `2` (zero-based index)

Updated Array:
```text
10 20 25 30 40
```

### 2. Array Deletion

In this task, I deleted an element from a specified position in the array.

**Working:**
- First, I displayed the original array.
- I selected the position of the element to delete.
- I shifted the remaining elements one position to the left.
- I reduced the array size by one.
- Finally, I displayed the updated array.

**Example:**

Original Array:
```text
10 20 30 40 50
```

Position to delete: `2` (zero-based index)

Updated Array:
```text
10 20 40 50
```

During this lab, I learned:

- How to delete an element from a specific position.

- How to update the array size after insertion and deletion.

In this lab, I practiced insertion and deletion operations in C++. I understood that insertion requires shifting elements to the right, while deletion requires shifting elements to the left. This helped me understand how array operations work in Data Structures and Algorithms.
